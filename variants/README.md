# Variants

Planned deltas on top of the generic core. Each variant is one Markdown file
describing what the setup skill changes or adds — not a duplicated template
set.

- **work.md** — commercial projects: license rules for shipped dependencies,
  team conventions (shared `.claude/settings.json`, `CLAUDE.local.md` split).
  To be aligned with the team first; will start from a current client project
  as the reference standard.
- **thesis.md** — academic writing alongside code: authorship rules (no
  finished prose without agreement), report notes structure, Typst templates.
  Source material exists from an earlier handover package.

Not built yet — the generic core comes first.
